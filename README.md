# **Frutofeel**



Frutofeel es un emprendimiento enfocado en ofrecer productos elaborados a base de frutas, buscando brindar una propuesta atractiva y diferenciada para sus clientes.



Este proyecto consiste en el desarrollo de una aplicación web para Frutofeel, creada como proyecto final de programación. La aplicación permitirá presentar el emprendimiento y sus productos, y progresivamente incorporará las funcionalidades definidas durante el desarrollo del proyecto.
